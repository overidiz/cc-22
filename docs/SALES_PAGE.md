## Title
**CC-22 — Boutique Modular Multi-FX**

## Tagline (one line)
Four colour engines, twenty hand-tuned modes, ten independent EQs — chain them in
any order and shape the result on one live curve.

## Short description (the hook, 2–3 lines)
CC-22 is a modular colour processor: **Character, Movement, Diffusion, Texture** —
each with five distinct modes. Reorder the chain, sculpt with per-module and
global EQ, and watch the input spectrum move behind the curve. Warm, musical,
and built to stay safe at the extremes.

## Feature list
- **20 modes across 4 modules** — each one its own effect, not a preset:
  - *Character*: Drive · Sweeten · Fuzz · Howl · Swell
  - *Movement*: Doubler · Vibrato · Phaser · Tremolo · Pitch
  - *Diffusion*: Cascade · Reels · Space · Collage · Reverse
  - *Texture*: Filter · Squash · Cassette · Broken · Interference
- **Re-orderable signal chain** — drag modules into any order.
- **10 independent EQs** — global pre/post + a pre/post EQ for every module, all
  on one full-width curve with a **live input spectrum analyzer**.
- **Edit on the graph** — drag nodes for frequency + gain, scroll for Q,
  right-click for band type. No knob clutter.
- **Boutique, safe DSP** — denormal-flushed, clamped feedback, no runaway, no NaN;
  validated with pluginval (strictness 8) and clap-validator.
- **VST3 · CLAP · Standalone**, 64-bit.

## What's in the box
- One-click Windows installer (VST3 + CLAP + standalone)
- Factory presets covering all 20 modes

## System requirements
- Windows 10 / 11 (64-bit)
- A VST3 or CLAP host (or run the standalone)
